## DEC-016 · M0 离线组件依据（2026-10-10）

关联 TASK-004、REQ-001、002、003、010、015。沿用 DEC-009 中 M0 方案，在本次明确实施授权内采用，不锁定后续服务栈。实际环境 Python 3.14.7，自带 SQLite 3.50.4；不安装新组件。[Python 官方 sqlite3 接口](https://docs.python.org/3.14/library/sqlite3.html) 支持本地数据库、参数绑定、事务与只读 URI；本实现显式事务块提交，查询使用参数绑定。[Python 许可](https://docs.python.org/3.14/license.html) 提供 PSF 许可及随附第三方声明；[SQLite 官方许可说明](https://www.sqlite.org/copyright.html) 核心代码属公有领域。本次仅使用已安装运行时，不复制或分发其二进制；未来打包时保留对应版本许可声明并另核对分发内容。

SQLite 无独立服务器，适合本机单进程离线回放；本次未选网络服务、外部 AI、QQ 组件或新数据库。最小 schema 用 messages 中显式账号 / 群 / namespace / 上游 ID 唯一约束替代草案独立身份映射表，段与观测有外键；仅用于 synthetic.v1。原文到期时间记录但不自动删除，真实留存仍依赖 TASK-008。新来源接入需独立适配、验证身份稳定性并版本迁移，不将该合成唯一规则用于真实 QQ。
