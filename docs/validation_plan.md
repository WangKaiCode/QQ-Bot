## M1：真实接入与分析

### TASK-013 已实现的来源阅读子集

2026-10-10，合成数据实际浏览器验证，结果见 task013_validation.md；不代替真实接入与甲方验收。

| 案例 | 关联需求 | 判定与实测 |
| --- | --- | --- |
| AC-011 | REQ-003、009、010 | 按账号 / 群浏览并搜索转发文本，切换范围后详情重置；通过 |
| AC-012 | REQ-003、010 | 嵌套转发可折叠，图片与未知格式状态分开，来源与前后文对应样本；通过 |
| AC-013 | REQ-009、010 | 25 条样本分页 20 / 5，末页边界与无结果提示明确；通过 |
| AC-014 | REQ-009、015 | 窄屏来源布局无横向溢出；特殊 HTML 内容按纯文本显示，无注入元素或弹窗；通过 |
| AC-015 | REQ-002、010、018 | 网页导入计数可对账、错误定位到行、不显示失败原文；只读接口不修改库；通过 |

1. 授权测试群由人工记录有限样本数量和类型；逐条比对本应用、QQ 可见记录及导出结果。对照范围内通过不代表所有消息绝对完整。
2. 制造传输断线与进程重启，记录缺口，测试自动补录范围、失败和仍未恢复区间；区分无消息与上游不可获取。
3. QQ / NapCat / QCE 重启前后比对 ID，核实原生 ID / 序号映射；不依赖文档中的旧缓存容量。
4. 深层转发、媒体过期、撤回、上游超时和权限变化分别验证。客户端跳转单独记录成功条件，不能以应用内链接冒充精确跳转。
5. 检查模型引用有效、外发字段符合批准策略、任务重试幂等、小时 / 日窗口和迟到补算。跨批证据与伪造 ID 必须被拒绝。
6. 使用人工标注样本计算 precision / recall，并单独报告图片或转发内容漏筛。阈值由样本基线与甲方需求确认后记录。
7. 清理只在期限确认后执行；验证正文、段、附件、索引、缓存与摘录；收藏例外和摘要来源过期显示符合策略。
8. 峰值、队列积压、长时运行与磁盘不足独立测试；2C2G40G 服务器能力在目标机器上确认。
