## 推荐交付路线

先交付单账号、指定群、可回放的采集与来源闭环；再增加小时筛选 / 日报和 Web 页面。Windows 为开发及首轮验证环境，云端部署后置。2C2G40G 暂按候选运行环境看待，不承诺本地模型、图片识别和 QQ 同机全套运行。

第一个编程增量为 M0：只使用合成样本，完成离线导入、幂等去重、转发结构、失败状态和来源查询。它不接 QQ、不外发聊天、不发送通知、不自动删除真实数据。M0 是技术验证，不冒充可全天使用的产品。

M1 为可用 MVP：少量授权群实时采集、补录状态、关键词 / 自然语言主题筛选、每小时摘要、每日摘要、信息流 / 通知中心、应用内来源与上下文、收藏 / 忽略记录及已确认规则的短期保留。具体 AI 供应商、外发字段和删除期限另行确认。

M2 为扩展：自动新话题发现、反馈推荐、语义搜索、多账号、OCR / 多模态、Web Push / QQ 私聊 / 邮件，以及客户端精确跳转能力验证。延后不等于删除需求；尤其图片、转发与跳转应在 M1 前完成能力验证，避免依赖不可实现的前提。
