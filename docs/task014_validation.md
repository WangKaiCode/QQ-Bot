## 证据补充与解释限制

自动化命令如上；CLI 使用 data/source-demo.db，自定义 data/qa-rules.json（忽略目录，不入库）。实际网页服务分别运行于 8767（阅读演示）和 8768（独立特殊文本 QA）；QA 服务检查后停止。浏览器 error / warn 日志为空，临时窄屏已恢复默认。

多 Agent 独立测试发现两个可复现失败：窗口内 e1 编号跨窗口重用、短原文错误接受省略号；修复为窗口 / 消息 / 路径哈希与有条件截断后复测通过。只读审查指出 Windows 极端日期错误分类，改为 epoch + timedelta 并统一 INVALID_WINDOW，新增边界测试通过。CSS 检查修正预览样式意外落入移动媒体块的问题，桌面与窄屏实际复核。

30,000 限额测试使用轻量 SQL 消息副本（无段），验证计数门槛而非全量文本性能；本轮没有重做 30,000 条真实导入吞吐基线。CLI 部分窗口范围由 requested_range 表示。
